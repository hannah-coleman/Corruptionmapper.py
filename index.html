ARKANSAS PUBLIC RECORDS ROADMAP

Turn an open question into a request

Verify current rules with counsel
01

Define the record

Describe the agency-held record, date range, custodian, and preferred format. Request records, not conclusions about a person.

02

Use the right law

For Paragould or Greene County, start with an Arkansas public-records request to the record-holding agency. Federal FOIA is for federal agencies.

03

Preserve the response

Log submission time, tracking number, correspondence, fees, redactions, and the exact files received back into the evidence index.

FIELD GUIDE / VERIFIED AUDIT

Build a case that survives scrutiny

0 of 8 complete
01

Write the audit question

Choose one testable question, such as whether a procurement followed the published process or whether a disclosed relationship required recusal.

02

Freeze the scope

Set Paragould and Greene County, a date range, named agencies, and record types. Do not expand scope because a name appears in a document.

03

Collect public social evidence lawfully

Capture only publicly viewable posts, complaints, and videos using permitted access. Record the original URL, account name, post time, capture time, platform, and a hash or unchanged download when allowed.

04

Build the source register

For every item, record the issuing body, exact URL or file, publication date, capture date, page or paragraph, and local hash when possible.

05

Separate fact from inference

Label each statement as sourced fact, reasonable inference, or unresolved lead. A complaint, shared address, or meeting is not proof of misconduct.

06

Request the missing records

Ask the record custodian for narrowly described public records. Preserve fees, delays, exemptions, redactions, denials, and appeal deadlines.

07

Corroborate independently

Confirm important claims with a second primary source, a separate custodian, or an on-the-record response. Log contradictions instead of hiding them.

08

Run a pre-publication review

Have counsel review privacy, defamation, privilege, sealed records, retaliation risk, platform terms, and the difference between an allegation and a proven finding.
